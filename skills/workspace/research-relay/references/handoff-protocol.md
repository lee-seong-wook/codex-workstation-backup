# Handoff Protocol

Use this reference when a research task spans multiple agents, sessions, or handoff files.

## Required Fields

Every `HANDOFF.md` should include:

- Current stage.
- Last worker or reviewer.
- Completed work with evidence paths.
- Open questions and blockers.
- Next owner.
- Next actions in priority order.
- Files that must be read before continuing.

## Handoff Rules

- Write decisions, not just summaries.
- Include exact file paths for outputs, logs, data, drafts, and figures.
- Mark speculative claims as speculative.
- Keep the next action concrete enough that a fresh agent can start without reading the entire conversation.
